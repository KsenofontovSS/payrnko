# TASK-10: Раздел «Раскрытие информации» (регуляторный)

## Метаданные
- **ID:** TASK-10
- **Приоритет:** Критический (требование ЦБ РФ)
- **Роли:** Frontend-разработчик, Верстальщик
- **Зависимости:** TASK-03, TASK-05
- **Оценка:** 5–7 дней

---

## Цель

Реализовать раздел раскрытия информации — обязательный по ФЗ-395-1 и Указанию ЦБ РФ № 2172-У. Раздел включает главную страницу с категориями и 4 подстраницы: финансовая отчётность, нормативы, аудиторские заключения, управление рисками. Документы с фильтрацией, встроенным PDF-просмотрщиком и скачиванием.

---

## Что нужно сделать

### 1. Главная страница раздела (`/disclosure`)

**Структура (раздел 6.2 дизайн-спецификации):**
- Информационный баннер вверху: «Раскрытие информации в соответствии с ФЗ-395-1 «О банках и банковской деятельности» и Указанием ЦБ РФ № 2172-У»
  - Стиль: фон `#EBF8FF`, иконка Info, border-left 4px `#2B6CB0`
- Категории в виде **аккордеона** (desktop) или **табов** (по выбору дизайнера):
  1. Финансовая отчётность → `/disclosure/financial`
  2. Обязательные нормативы → `/disclosure/standards`
  3. Аудиторские заключения → `/disclosure/audit`
  4. Управление рисками → `/disclosure/risks`
  5. Учредительные документы → `/about/documents` (ссылка)

Каждая категория показывает краткое описание и кнопку «Перейти к документам».

### 2. Страница «Финансовая отчётность» (`/disclosure/financial`)

**Данные:** `getDocuments({ category: 'financial' })`

**Функционал:**
- Фильтр по году (dropdown или кнопки: 2024, 2025, 2026)
- Таблица документов:

| Название | Дата публикации | Формат | Действия |
|----------|----------------|--------|----------|
| Форма 0409101 (01.01.2025) | 15.02.2025 | PDF | [Просмотр] [Скачать] |
| Форма 0409123 (Q4 2024) | 20.01.2025 | PDF | [Просмотр] [Скачать] |

- Кнопка «Просмотр» → открывает встроенный PDF-просмотрщик (PDF.js)
- Кнопка «Скачать» → прямая загрузка файла

**Формы отчётности ЦБ (раздел 4.1.4 ТЗ):**
- 0409101 — Оборотная ведомость
- 0409123 — Расчёт собственных средств
- 0409134 — Расчёт обязательных нормативов
- 0409135 — Информация о нормативах

### 3. Страница «Обязательные нормативы» (`/disclosure/standards`)

**Данные:** `getDocuments({ category: 'standards' })`

Аналогичная структура: фильтр по году, таблица, просмотр, скачивание.

### 4. Страница «Аудиторские заключения» (`/disclosure/audit`)

**Данные:** `getDocuments({ category: 'audit' })`

Годовые заключения. Фильтр по году. Список DocumentCard.

### 5. Страница «Управление рисками» (`/disclosure/risks`)

**Данные:** `getDocuments({ category: 'risks' })`

Политики и процедуры управления рисками. Список документов.

### 6. PDF-просмотрщик (`src/components/sections/PDFViewer.tsx`)

**Библиотека:** PDF.js (react-pdf или @react-pdf-viewer/core)

**Функционал:**
- Модальное окно или встроенный блок
- Навигация по страницам (prev / next / номер)
- Зум (fit width, fit page, + / -)
- Кнопка скачивания
- Кнопка закрытия
- Loading spinner при загрузке

**'use client'** — клиентский компонент.

### 7. Sidebar-навигация раздела

На всех подстраницах disclosure — sidebar с ссылками на все категории. Текущая категория выделена.

## Тестирование

### Unit-тесты
- Фильтрация документов по году: выбрать 2025 → только 2025-е
- PDFViewer: рендер, loading state, error state
- DocumentCard: рендер с данными, клик по «Скачать»
- Аккордеон категорий: раскрытие/сворачивание

### Integration-тесты
- API documents с фильтром category=financial → корректные данные
- API documents с фильтром year=2025 → корректные данные
