## Цель

Реализовать ленту новостей (`/news`) с пагинацией и фильтрацией по рубрикам, детальные страницы новостей (`/news/:slug`) и RSS-ленту (`/rss.xml`).

---

## Что нужно сделать

### 1. Лента новостей (`/news`)

**Данные:** `getNewsArticles({ locale, page, pageSize: 9, category })`

**Структура:**
- Breadcrumbs: Главная > Новости
- H1: «Новости»
- Фильтр по рубрикам (горизонтальные кнопки-табы):
  - Все
  - Регуляторные изменения
  - События компании
  - Обновления тарифов
- Сетка карточек: 3 колонки (lg), 2 (md), 1 (sm)
- Пагинация внизу: номера страниц + «Назад» / «Далее»

**Карточка новости:**
- Cover image (если есть, next/image, aspect-ratio 16:9) или placeholder
- Дата публикации (formatted, body small)
- Рубрика (Badge)
- Заголовок (H3, link → /news/:slug)
- Excerpt (2 строки, truncated)

**Фильтрация:** клиентская (URL query params: `/news?category=regulatory&page=1`). При смене фильтра — обновление URL без перезагрузки (useRouter + shallow).

**Пагинация:** 9 новостей на страницу. Компонент пагинации: `[< Назад] [1] [2] [3] ... [N] [Далее >]`.

### 2. Детальная страница новости (`/news/[slug]`)

**Данные:** `getNewsBySlug(slug, locale)`

**Структура:**
- Breadcrumbs: Главная > Новости > [Заголовок]
- Дата + Рубрика (Badge)
- H1: заголовок
- Cover image (полноширинная, aspect 16:9)
- Контент (Rich Text из CMS)
- Навигация: «← Предыдущая новость» / «Следующая новость →»
- Блок «Другие новости» (3 последние, кроме текущей)

**SSG:** `generateStaticParams` для всех опубликованных новостей. ISR: 60 секунд.

### 3. RSS-лента (`/rss.xml`)

**Реализация:** через Next.js Route Handler (`app/rss.xml/route.ts`).

**Формат:** RSS 2.0 с полями:
- `<title>`, `<link>`, `<description>`, `<pubDate>`, `<guid>`
- Последние 50 новостей
- `Content-Type: application/rss+xml`

### 4. Пустое состояние

Если новостей нет или фильтр не дал результатов: «Новостей в этой категории пока нет» с иллюстрацией или иконкой.

## Тестирование

### Unit-тесты
- Лента: рендер с 0, 1, 9 новостями
- Карточка: с cover image и без
- Пагинация: рендер с 1 страницей (скрыта), с 5 страницами
- Фильтр: выбор категории → корректный callback
- RSS route: генерация валидного XML

### E2E-тесты
```

1. /news → 200, карточки новостей видимы
2. Фильтр "События компании" → URL обновляется, карточки фильтруются
3. Пагинация: клик "Далее" → page=2 в URL, карточки обновляются
4. Клик на заголовок новости → /news/:slug
5. Детальная страница: заголовок, дата, контент, breadcrumbs
6. Навигация prev/next → переход к другой новости
7. /rss.xml → Content-Type: application/rss+xml, валидный XML
8. Mobile (375px): карточки в 1 колонку, пагинация компактная
9. axe-core: 0 critical/serious на обеих страницах
```
