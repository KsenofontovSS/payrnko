## Цель

Реализовать страницу `/contacts` с контактной информацией, интерактивной картой Яндекс.Карт, формой обратной связи с валидацией и hCaptcha.

---

## Что нужно сделать

### 1. Контактная информация

**Данные:** `getCompanyInfo()` из CMS

**Двухколоночный layout (раздел 6.4 дизайн-спецификации):**

| Левая колонка | Правая колонка |
|---------------|----------------|
| Контактная информация | Интерактивная карта |

**Левая колонка — информация:**
- Адрес: 196246, г. Санкт-Петербург, ш. Пулковское, д. 40, к. 4, литера Д, офис С53
- Телефон (кликабельный `tel:`)
- Email (кликабельный `mailto:`)
- Режим работы
- Реквизиты: ИНН, ОГРН, рег. номер ЦБ

Каждый пункт с иконкой (Lucide: MapPin, Phone, Mail, Clock, FileText).

### 2. Интерактивная карта (`src/components/sections/YandexMap.tsx`)

**API:** Яндекс.Карты JavaScript API v3

**Реализация:**
- `'use client'` компонент
- Загрузка SDK через `<script>` (динамически, после mount)
- Маркер офиса на координатах из CompanyInfo (`map_coordinates`)
- Balloon (всплывающая подсказка) с адресом
- Zoom controls
- Высота карты: 400px (desktop), 300px (mobile)
- API-ключ из `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`

**Fallback:** если карта не загрузилась — статическое изображение + ссылка «Открыть в Яндекс.Картах».

### 3. Форма обратной связи (`src/components/forms/ContactForm.tsx`)

**'use client'** компонент.

**Поля:**
| Поле | Тип | Валидация |
|------|-----|-----------|
| Имя | text | required, 2–100 символов |
| Email | email | required, valid email |
| Тема | text | required, 5–200 символов |
| Сообщение | textarea | required, 10–5000 символов |
| Согласие на обработку ПД | checkbox | required, must be true |

**Библиотеки:** React Hook Form + Zod

**hCaptcha:**
- Компонент `@hcaptcha/react-hcaptcha`
- Site key из `NEXT_PUBLIC_HCAPTCHA_SITE_KEY`
- Токен отправляется вместе с формой

**Отправка:**
```typescript
const result = await submitContactForm(data);
```

**Состояния кнопки отправки (раздел 6.4):**
1. **Обычное:** «Отправить сообщение» (Primary button)
2. **Загрузка:** спиннер + «Отправка...» (disabled)
3. **Успех:** зелёная галочка + «Сообщение отправлено!» (Success Green)
4. **Ошибка:** красный текст + «Ошибка отправки. Попробуйте позже.» (Error Red)

**Валидация:**
- Inline-ошибки под каждым полем (красный текст, анимация appear)
- Валидация при blur + при submit
- Ошибки на языке интерфейса (i18n)

**После успешной отправки:** форма очищается, показывается success-сообщение на 5 секунд.

### 4. Ссылка «Согласие на обработку ПД»

Текст: «Нажимая кнопку, вы соглашаетесь с [Политикой конфиденциальности](/privacy)»
Чекбокс обязателен для отправки.

## Тестирование

### Unit-тесты
- Форма: рендер всех полей
- Валидация: пустое имя → ошибка, невалидный email → ошибка
- Submit с валидными данными → `submitContactForm` вызывается
- Submit без captcha → форма не отправляется
- Loading/Success/Error состояния кнопки

### Integration-тесты
- Форма + API mock: отправка → success response → UI обновляется
- Форма + API mock: отправка → error response → показать ошибку

### E2E-тесты
```
e2e/contacts.spec.ts:

1. /contacts → 200, адрес и телефон видимы
2. Карта Яндекс загружается (проверить наличие iframe или canvas)
3. Клик по телефону → href содержит "tel:"
4. Клик по email → href содержит "mailto:"
5. Форма: отправить пустую → ошибки валидации на всех полях
6. Форма: заполнить невалидный email → ошибка "Введите корректный email"
7. Форма: заполнить все поля корректно + captcha → отправить → success message
8. Форма: без согласия ПД → кнопка disabled или ошибка
9. Mobile (375px): карта и форма в стопку, полноширинные
10. axe-core: 0 critical/serious
11. Keyboard: Tab проходит по всем полям формы, Enter отправляет
```
