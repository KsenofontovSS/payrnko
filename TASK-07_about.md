# TASK-07: Раздел «О компании»

## Метаданные
- **ID:** TASK-07
- **Приоритет:** Высокий
- **Роли:** Frontend-разработчик, Верстальщик
- **Зависимости:** TASK-03, TASK-05
- **Оценка:** 3–4 дня

---

## Цель

Реализовать раздел «О компании» из 3 страниц: основная `/about` (история, миссия, лицензия, структура), `/about/management` (руководство) и `/about/documents` (учредительные документы). Данные из CMS.

---

## Что нужно сделать

### 1. Страница «О компании» (`/about`)

**Layout:** контентная страница с sidebar-навигацией (desktop) или табами (mobile).

**Секции:**
- **История и миссия** — Rich Text из CMS (Page content type, slug: "about")
- **Лицензия и регистрация** — блок с реквизитами из CompanyInfo:
  - Рег. номер ЦБ РФ: 3566
  - ИНН: 9810007307
  - ОГРН: 1267800007650
  - Уставный капитал: 120 000 000 руб.
  - Тип лицензии: Лицензия на осуществление банковских операций (расчётная НКО)
  - Отображать в карточке с иконкой Shield
- **Организационная структура** — схема или Rich Text из CMS

**Sidebar (desktop):**
- О компании (текущая, выделена)
- Руководство → /about/management
- Документы → /about/documents

### 2. Страница «Руководство» (`/about/management`)

**Данные:** `getTeamMembers(locale)` — сортировка по order

**Карточка руководителя:**
- Фото (или placeholder-аватар с инициалами)
- ФИО (H3)
- Должность (body small, `#4A5568`)
- Краткая биография (при клике раскрывается или в модалке)

**Layout:** grid 2 колонки (desktop), 1 (mobile)

### 3. Страница «Документы» (`/about/documents`)

**Данные:** `getDocuments({ category: 'charter' })` — учредительные документы

**Отображение:** список DocumentCard компонентов с кнопкой скачивания.

Документы: Устав, Свидетельство о регистрации, Лицензия ЦБ РФ.

### 4. Breadcrumbs

На всех внутренних страницах: `Главная > О компании > Руководство`
Компонент Breadcrumbs из TASK-02, с микроразметкой Schema.org BreadcrumbList.

---

## Критерии приёмки

- [ ] `/about` отображает историю, миссию, реквизиты компании
- [ ] Реквизиты корректны (ИНН, ОГРН, рег. номер совпадают с ТЗ)
- [ ] `/about/management` отображает список руководителей с фото и должностями
- [ ] `/about/documents` отображает учредительные документы с кнопкой скачивания
- [ ] Sidebar-навигация работает на desktop, табы на mobile
- [ ] Breadcrumbs отображаются на всех вложенных страницах
- [ ] Контент загружается из CMS
