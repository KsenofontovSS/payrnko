## Что нужно сделать

### 1. Cookie-баннер (`src/components/forms/CookieBanner.tsx`)

**'use client'** компонент.

**Поведение:**
- Появляется внизу страницы при первом визите (position: fixed, bottom: 0)
- Текст: «Мы используем файлы cookie для улучшения работы сайта. [Подробнее](/privacy)»
- 2 кнопки: «Принять» (Primary) и «Отклонить» (Secondary)
- При принятии → устанавливается cookie `cookie_consent=accepted`, баннер скрывается
- При отклонении → `cookie_consent=declined`, баннер скрывается, аналитика НЕ загружается
- Баннер не показывается повторно если cookie уже установлен
- Анимация: slide-up при появлении, fade-out при закрытии

**Стиль:**
- Фон: белый, тень сверху
- Max-width: container (1200px), отступы по бокам
- Z-index: 40 (под модалками, но над контентом)

### 2. Управление согласиями (`src/hooks/useCookieConsent.ts`)

```typescript
type ConsentStatus = 'pending' | 'accepted' | 'declined';

function useCookieConsent(): {
  status: ConsentStatus;
  accept: () => void;
  decline: () => void;
  isAccepted: boolean;
}
```

Cookie `cookie_consent`:
- Срок: 365 дней
- SameSite: Lax
- Secure: true (в production)

## Тестирование

### Unit-тесты
- `useCookieConsent`: начальное состояние `pending`, accept → `accepted`, decline → `declined`
- CookieBanner: рендер при pending, скрытие при accepted/declined
- YandexMetrika: не рендерится если consent !== accepted

### E2E-тесты
```
e2e/cookie-consent.spec.ts:

1. Первый визит → cookie-баннер видим внизу страницы
2. Клик "Принять" → баннер исчезает
3. Перезагрузка → баннер НЕ появляется (cookie сохранён)
4. Проверка cookie: cookie_consent=accepted в browser cookies
5. Яндекс.Метрика: при accepted → скрипт metrika присутствует в DOM
6. Отклонение: clearCookies → клик "Отклонить" → Метрика НЕ в DOM

e2e/privacy.spec.ts:
7. /privacy → 200, заголовок "Политика конфиденциальности"
8. Оглавление: якорные ссылки скроллят к нужной секции

e2e/sitemap-page.spec.ts:
9. /sitemap → 200, ссылки на все основные страницы
10. Каждая ссылка на карте сайта кликабельна и не ведёт на 404
```
