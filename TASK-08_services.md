## Цель

Реализовать каталог услуг (`/services`) и детальные страницы каждой услуги (`/services/:slug`). Данные из CMS (Content Type: Service).

---

## Что нужно сделать

### 1. Каталог услуг (`/services`)

**Данные:** `getServices(locale)` — отсортировано по order

**Layout:** заголовок H1 + описание + сетка карточек

**Услуги РНКО (раздел 4.1.3 ТЗ):**
1. Открытие и ведение банковских счетов юридических лиц
2. Осуществление расчётов по поручению юридических лиц
3. Переводы денежных средств без открытия банковского счёта
4. Инкассация денежных средств, платёжных и расчётных документов
5. Кассовое обслуживание юридических лиц
6. Купля-продажа иностранной валюты в безналичной форме

**Карточка услуги (расширенная):**
- Иконка (Lucide, 48px, `#2B6CB0`)
- Заголовок (H3)
- Краткое описание (short_description)
- Кнопка «Подробнее →» → `/services/:slug`
- Hover: тень + translateY(-2px)

**Сетка:** 3 колонки (lg), 2 (md), 1 (sm). Gap: 24px.

**Анимация:** staggered fade-in при загрузке.

### 2. Детальная страница услуги (`/services/[slug]`)

**Данные:** `getServiceBySlug(slug, locale)`
- Если не найдена → `notFound()` (Next.js 404)

**Layout:**
- Breadcrumbs: Главная > Услуги > [Название услуги]
- Иконка (64px) + Заголовок H1
- Полное описание (Rich Text из CMS) — `full_description`
- Sidebar: ссылки на другие услуги (мини-навигация)
- Внизу: CTA-блок «Заинтересовала услуга? Свяжитесь с нами» → `/contacts`

### 3. SSG / ISR

- Страницы услуг генерируются статически при сборке (`generateStaticParams`)
- ISR ревалидация: 60 секунд
- При добавлении новой услуги в CMS — страница создаётся автоматически
